01 / 创作工房

灵感、素材与故事，各有安放的位置。

轻柔的画面与留白服务于创作。首页可以查找作品、区分创作与发布状态；进入项目后，以章节、场景和镜头卡组织内容。

02 / 本轮重点 · 声音与配音

先认识声音，再把它交给角色。

音色库按声线、年龄感、适用人物和样音语言整理。听过再选择，也能看到已分配的角色。五个示例角色有中日双语合成声线，资料保留来源和授权说明。

01 / 试听

比较合适的声线

直接听样音，了解语气、年龄感和适用人物。

02 / 分配

角色绑定一次

为故事中的角色选择固定音色，后续对白自动沿用。

03 / 写作

后台准备配音

开启自动配音，写完稍等；系统翻译、合成、关联并保存。

04 / 调整

保留精修空间

可暂停、重试或切到手动试听。修改台词只更新对应片段。

绑定的是“谁的声音”，新文字仍需要合成。DreamChord 自动安排这些步骤，并复用有效结果。自动处理发生在编辑器打开期间；离开后停止后续提交，已提交的服务端任务可以完成，下次继续时可复用。公开播放器播放已保存的音频。
03 / 试听，而不只是看截图

同一个角色，两种配音语言。

游戏文字默认中文。作者输入中文并选择日语配音时，系统准备日语台词和音轨；原来的中文显示保留。下面是晴音声线的两条真实内置合成样音。

晴音 · 中文样音

清亮少女声线

“剪贴板是空的，云端备份也在一行行变白。”

晴音 · 日语样音

中文显示，日语开口

クリップボードが空っぽ。クラウドのバックアップまで、一行ずつ白くなってる。

样音由 Qwen3-TTS 预置合成声线生成，非真人声音克隆。来源与许可证 · 实际表现请试听判断。

04 / 场景、分支与演出

写作是主线，结构检查随时可见。

镜头卡继承背景和在场人物，分支分别计算舞台状态。需要总览时切到流程图；完整预览使用半身立绘、对白、选择和独立音频通道。

从编辑到游玩

把写下的场景，交给玩家。

正式播放采用半身立绘、清晰的对白区与独立音频通道。字幕与配音语言分别选择，历史、自动播放与分支选择保留在游戏里。

05 / 理解项目的创作伙伴

把建议变成可审核的修改。

创作 Agent 结合本地意图路由、项目上下文、分层记忆和白名单工具。无 API Key 也可做项目盘点、结构化导入与确定性分析；外部模型增强开放式续写与润色。

06 / 在自己的电脑上开始

创作留在本机，能力按需开启。

Windows 10/11、Node.js 20+。克隆后双击启动器；本地模型单独安装，日常在 DreamChord 内启停和使用。项目使用 React / TypeScript、Express、Prisma / SQLite 和共享剧情领域包。
