# 第六章：在雨停以前回信

夏禾要在四月二十六日前回应下一轮排练邀请。她与沈芸确认可能的换班，同时亲自询问巡演的费用和住宿条件；她的回信只承诺参加下一轮，并不等于正式录取。陆青在档案室获准手抄部分记录，发现红纸曾被另存，但这条旧记录无法证明画内今天发生变化的原因。

两条选择分别先调查换班与先整理电话问题，各自呈现未完成的信息和人物回应，再汇合。故事仍在连载，尚未到最终结局。

## 安装与保护

先构建故事包，执行 `pnpm --filter dreamchord-server exec tsx prisma/installPaintChapterSix.ts --check` 预检，备份数据库后用 `--apply` 追加。更新只接受与冻结基线匹配的公开官方作品，检查六个既有篇章、角色、参考音色和素材；已有作者修改或私人副本不会被覆盖。重复执行为无写入的 `current`。

## 素材与验证

雨中档案室由 OpenAI image_gen 参照既有画风生成；原图、运行文件及 SHA-256 记录在 `source-assets/paint-chapter-six/art-manifest.json`。21 句日语对白沿用现有六角色的固定参考音色，由 GPT-SoVITS v2ProPlus 合成。所有音频已检查文件和削波；自动识别对 `pc6-join-1-ja` 在重生成后仍标记待检查。尚未完成人耳听感验收，识别结果不等同于发音或表演验收。
