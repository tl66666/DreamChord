# 2026-10-28 配音与界面验收

## 已实现

- 默认中文字幕；字幕和配音语言独立设置，切换语言保留剧情位置。
- 中文输入自动翻译成日语，再生成日语配音。可查看实际朗读译文，调整后重录。
- 角色绑定音色保存在服务器，新增对白按说话角色沿用。编辑器集中配置、本章批量生成、试听排除、统一应用；应用结果跟随正常自动保存，并支持一次撤销。
- 已有有效音频默认保留；改稿、已记录的音色变化会进入待生成列表，也支持显式重录。
- 正在生成时改稿、改译文或更换音轨，旧候选不会覆盖新内容。服务重启后，中断任务显示失败和重试原因，不会永久卡在生成中。
- 音色编辑、停用/恢复、受引用保护的删除、参考片段解除和角色解绑；音乐多标签筛选、持续试听和编辑。
- 统一素材、Agent、发现、设置导航，登录/注册布局，编辑器正文与紫色动作层级。新增两张装饰插画，来源见 `apps/web/public/assets/ui/PROVENANCE.md`。

## 内容与来源

官方示例有 90 个日语对白/字幕/选项节点，原分支和结局结构保持一致。角色库内五款双语合成声线、22 段起始音频覆盖开场与关键节点；不是全剧配音。实际界面验收又为 `s2-d1` 生成并关联了一条日语配音，保留原中文“警告：强制恢复会占用现实锚点。”。

配乐共 13 首 TERNOX CC0 真人作曲视觉小说配乐，带作者、来源、剧情用途、时长和哈希；运行版本统一响度。声音是可追溯的 Qwen3-TTS 预置合成声线，不冒充真人录音或已训练的专属声优。

本机翻译采用 Qwen3 4B Q4，CPU 按需运行。模型文件 SHA-256：`7485fe6f11af29433bc51cab58009521f205840f5b4ae3a32fa7f92e8534fdf5`。llama.cpp b11946 Windows CPU 归档 SHA-256：`8a702bb07c873b133c56eb3acd92a48d7c5c9ad339c6435eddc5185e46e1a043`。

小模型试验曾出现“放学后”误译为“毕业后”等问题，未作为生产默认。实际 Qwen3 4B 新句测试保留了“明日放課後”。地名、敬语、人物语气仍应校对；不把自动翻译或技术自检当作人工质量验收。

技术实测：中文新句 3.12 秒，日文新句 6.78 秒，两者均无削波；日文一轮生成约 24 秒，含声音模型切换。独立 Whisper ASR 识别到了“明日ほうかご一緒に海を見に行こう”，与目标主句一致，少量同音识别误差保留在报告中。

CosyVoice 日文指令/参考模式曾出现明显错读，已拒绝该结果；生产路径为中文 CosyVoice、日文 GPT-SoVITS，等待旧进程退出再切换。声音/翻译模型放在运行目录，未提交到 Git。
