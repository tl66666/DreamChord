# 故事编辑器、Agent 和音乐控制验收

## 实现

- 设置与 Agent 直接填写模型 ID，保留旧模型和密钥；保存校验及存储失败提示。编辑中的模型 ID 明确点击应用后生效。
- 当前镜头正确传入 Agent；显式选择的场景不再被编辑器选择覆盖；空目标不能提交。启动防重复、失败保留输入、当前浏览器会话保留草稿和运行引用。
- 草稿转换请求绑定来源会话且只消费一次；当前任务/审批未处理时等待。运行恢复返回所属章节，异章禁止应用/撤销；编辑器接收结果再检查章节；未保存图的保护回调完整贯通。
- BGM 音量 0–100%、延续调音、0–30 秒过渡。换素材保留混音；作者过渡与对白压低独立；相同音乐 URL 不重新起播。中间预览沿可达路线继承音乐，不重放早先配音/音效；首次自动播放被拦截时，在后续剧情操作中重试音乐。
- 官方示例的 4 个播放提示更新为 55%、45%、55%、50%；播种只更新固定官方项目中旧默认电平一致、正文与曲目未改动的提示，并递增章节版本。私人副本保留。
- Agent 工作区撑满弹窗；高级配置折叠，发送区更易到达；场景编号不折行，编辑镜头时同步右侧预览；体检报告不再被识别为剧情草稿。

## 自动化验证

- 新增行为用例先失败后实现，包括自定义模型、0 音量、换曲参数保持、同曲连续播放、3 秒过渡与配音共存、预览路径、明确目标、延迟 POST 卸载恢复、任务消费和异章审批。
- `pnpm -r test`：**37 domain + 273 server + 222 web = 532 条通过**。
- `pnpm lint`、`pnpm build` 通过。
- `pnpm test:readiness`、`pnpm test:presentation`、`pnpm test:curtain` 通过。
- 独立审查发现的任务重复、过渡中断、延迟启动恢复、跨章节图替换、跨会话待执行正文问题均已修复并复查。

## 实际操作

- 官方项目接口确认四个播放提示音量为 0.55 / 0.45 / 0.55 / 0.5。
- 私有示例镜头由 55% 调为 0%，保存后 API 确认为 0；随后恢复 55%。
- 从第三句直接预览：实际 Audio 对象包含沿途的 `backstage.ogg` 和当前句日语配音；音乐持续推进，配音结束后音乐电平恢复至 0.275（0.55 × 玩家混音 0.5）。中文字幕保持中文。
- 关闭重开 Agent 后未发送输入仍在。1440×900、1024×768、430×932、390×844 无横向溢出；后三个尺寸发送按钮底部分别在 730 / 906 / 818 像素，位于可视范围。
- 截图：[镜头音量](../screenshots/editor-audio-1440.png)、[桌面 Agent](../screenshots/agent-workspace-1440.png)、[手机 Agent](../screenshots/agent-editor-430.png)。新浏览器会话未记录到运行异常。
- 真实外部 LLM 未使用收费密钥调用；外部模型自由 ID 的传递由配置与服务端回归覆盖。模型能否调用仍取决于所用平台的权限和实际模型 ID。

## 参考与范围

- [Ren’Py Audio](https://www.renpy.org/doc/html/audio.html)：独立混音通道、曲目音量与持续调音。
- [WebGAL bgm](https://docs.openwebgal.com/script-reference/commands/bgm.html)：音乐播放/停止、音量和过渡参数。
- 延续音乐的分支汇合预览采用第一条找到的可达路径；需要确认特定分支时从选择处完整试玩。浏览器完整刷新时尚未取得服务端响应的 POST 无法仅依靠本地内存恢复；同窗口关闭/重开面板的延迟响应已覆盖，已返回任务引用随当前浏览器会话保存。
