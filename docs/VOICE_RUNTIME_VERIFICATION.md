## 解决的运行问题

1. 旧 Whisper 构建仍依赖 `pkg_resources`：在专用环境固定 `setuptools<81` 后预构建该依赖。
2. 官方模型加载需要 Matcha-TTS：桥接显式加入子模块路径。
3. 新版 Torchaudio 音频读取转向 TorchCodec：在桥接边界用 SoundFile 解码，保留 Torchaudio 重采样。
4. 官方文本规范化默认下载所有语言：安装器只预取中英文所需四个 FST，启动时使用本地路径。
5. 最初尝试共享完整 site-packages 导致 pip 改动 GPT 环境：已中止，并按 GPT-SoVITS 官方依赖清单修复；真实推理复核成功。最终安装器复制 Torch 为独立文件副本，不再共享可写包目录。
