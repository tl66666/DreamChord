# 2026-11-07 创作流程复查与修复

本轮保留现有章节—场景—镜头卡工作流和界面风格，优先修复实际复现的内容丢失、错连线与异步竞态。没有重做首页、加入另一套保存状态或绕过Agent建议审批。

## 编辑器

1. **移动镜头**：原先上移/下移仍保留旧顺序，并可能删掉移动区前后的普通连线。现在按阅读顺序重排，保留入口、出口、choice handle和标签；跨共享背景区域时补回必要的背景方向，移动仍可一步撤销。
2. **删除选项**：原先删除A后，剩下的B/C可能按旧索引接到A/B的去向。现在传递明确的删除索引，删除对应边，给剩余handle重新编号，并同步翻译选项；保留剩余目标场景。
3. **删除章节**：原先删除其他章也会加载第一章，清掉当前未保存内容与撤销历史。现在删除非当前章只刷新列表，保留当前图、选择和history；删除当前章先协调正在执行的保存、清理待执行自动保存并阻止并发章节操作，再加载存续章。保存失败不清掉正文。

变更集中在`shotGraphOperations.ts`、`ShotCardEditor.tsx`、`CardEditor.tsx`、`FlowEditor.tsx`，没有修改原故事内容来掩盖图谱错误。

## 创作Agent

1. **取消任务**：取消成为终态。状态采用条件更新，在模型、工具事件及持久化边界检查取消；中断不会进入本地fallback，也不会把任务恢复为completed/awaiting_approval。已经执行的单次IO可能返回，但不会继续下游产物写入。
2. **会话切换与历史**：异步消息请求受会话生命周期和请求版本约束；A的迟到结果不能盖到B正文。刷新合并已展开的历史，保留分页游标。独立复核发现的慢网饥饿也已修复：3秒轮询采用单会话单飞，4秒响应仍能持续显示结果。
3. **草稿保存失败**：失败会传回编辑组件，保持编辑状态和新正文，可直接重试；保存成功后防止在途旧刷新把正文回滚。

已有`当前模型 ID`和设置页均支持填写平台提供的任意模型名后应用，本轮核对并保留，没有再增加过时固定列表。API密钥不写入消息或日志。建议审核、应用和按版本撤销的边界继续保留。
