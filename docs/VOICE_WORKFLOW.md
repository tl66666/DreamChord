# 角色声音库与自动配音

## 创作者怎么用

1. 打开“素材库 → 角色音色”，按声线、年龄感、适用人物和样音语言筛选，先试听。
2. 点击“分配给角色”，选择自己的故事和角色。保存一次，后续台词沿用这条声线。
3. 在首页故事卡或编辑器的“故事设置”中分别设置默认字幕与配音语言；“角色配音”中的语言切换也会保存为此作品的配音默认值。**中文原稿保留**，日语配音由系统翻译后合成。
4. 保持“自动配音，写完后自动关联”开启，关闭配置面板，继续写作。停止修改约 2.2 秒后，系统优先准备当前场景，再补齐当前章节。
5. 编辑器状态栏显示等待、处理中、已就绪或错误。可以暂停；服务恢复后点击重试。需要逐句审听时关闭自动模式，使用手动批量生成、候选试听和统一应用。

分配音色时自动开启此项目的自动模式；如果作者明确暂停过，不会因为再次绑定就擅自恢复。自动模式保存在当前浏览器、当前项目下。作品的默认配音 / 字幕语言、声音的角色绑定、生成记录、正式音频和保存后的音轨保存在服务端，默认语言随项目备份恢复。播放器采用作品默认语言，读者可以按作品单独覆写；作者更新默认值后旧覆写失效。

## 为什么底层仍然分段

音色决定说话者的身份，新文字仍需要合成。作者无需逐句操作，但系统保留每段独立记录，以便定位台词、只更新改动部分、复用已完成结果、调整单句表演以及在玩家选择不同分支时准确播放。把整章合成一条长音频会让修改和分支处理变得困难。

## 实现入口

| 模块 | 位置 | 职责 |
| --- | --- | --- |
| 声线呈现 | `apps/web/src/voice/voiceCatalog.ts` | 兼容旧名称、保留自定义名称与说明、语言与有效参考筛选 |
| 试听 / 分配 | `VoiceCatalogCard.tsx`、`VoicePickerDialog.tsx`、`VoiceAssignmentDialog.tsx` | 素材库与编辑器共用试听卡片，保存角色绑定 |
| 配音计划 | `apps/web/src/voice/characterVoicePlan.ts` | 解析角色、查绑定、判断现有配音是否有效 |
| 自动控制器 | `apps/web/src/voice/automaticVoice.ts` | 串行合成、任务恢复、翻译、接受结果、变更保护 |
| 编辑器接入 | `AutomaticVoiceBar.tsx`、`FlowEditor.tsx` | 写作防抖、状态、暂停 / 重试、自动保存 |
| 手动精修 | `apps/web/src/editor/ProjectVoicePanel.tsx` | 固定声线、语言、手动候选、集中审听和应用 |
| 服务端任务 | `apps/server/src/routes/voices.ts`、`apps/server/src/voice` | 鉴权、任务队列、本地引擎和生成记录 |
| 播放 | `packages/story-domain`、`apps/web/src/player` | 字幕与音轨独立选择，过期配音不播放 |

## 必须保留的规则

- 只处理当前作者有权修改的项目，任务查询始终带 `ownerId`。恢复任务使用项目和章节过滤，最多读取最新 200 条；超大章节若有大量历史重录，可能无法命中更早缓存。
- 自动模式一次只提交一个片段，优先当前场景。等待、翻译、生成、接受结果后都重新检查项目、章节、角色、原文、绑定、参考片段以及原有音轨和日语文本。
- 台词或声线改变时不覆盖新数据；手动提供的有效录音不会无故替换。有效配音与已完成 / 在途任务尽量复用。
- 自动音频属于衍生数据，通过 `applyDerivedGraph / EditorHistory.replaceCurrent` 更新，不消耗作者撤销台词的步骤，不清空历史。
- 配音自动关联后仍交给原来的 `SaveCoordinator` 串行保存，不能再建一条旁路保存。
- 服务失败后暂停，用户明确重试后继续；不能无限重试、同时启动多个控制器或不断提交失效台词。
- 打开声音配置面板会暂停后台提交。离开编辑器停止后续提交；已提交的服务端任务可能继续完成，再次进入可恢复。当前没有脱离编辑器的整项目调度服务。

## 模型与边界

本机使用 CosyVoice3、GPT-SoVITS，并按语言管理模型切换；日语翻译可使用已配置的兼容模型或本机翻译组件。安装、引擎状态与授权参考片段见 [安装指南](GPT_SOVITS_SETUP.md)。Qwen3-TTS 用于生成可追溯的内置合成参考声线，当前没有接入为独立的在线流式服务。

官方示例有五个角色的双语声线、部分内置中日配音和 13 首 TERNOX CC0 配乐。**没有宣称所有剧情都已经预录，也没有宣称合成音与真人录音无法区分。** 新台词按绑定重新合成；声音资料、参考录音和音频素材分别管理。

公开播放器和导出内容使用已保存的音频；当前不在公开播放时即时调用 TTS，也不提供 GPT-SoVITS 权重训练界面或完整多轨音频剪辑。声音克隆使用作者本人或明确获得授权的参考录音。

## 验证

```bash
pnpm --filter dreamchord-web exec vitest run src/voice src/editor/ProjectVoicePanel.test.tsx src/editor/editorHistory.test.ts
pnpm --filter dreamchord-server exec vitest run src/routes/voices.test.ts src/voice
pnpm test:voice-runtime
```

实机验收：临时故事绑定音色 → 开启自动模式 → 写中文 → 等待状态就绪 → 重开确认音轨持久化 → 切日语确认中文原文未改 → 修改一句确认只更新该片段。测试项目通过项目服务删除，不能直接清空用户数据库或上传目录。
