## 情节与连续性

夏禾回到礼堂，独立说出接木颜色，与程见一起检查断口；原样锁存椅子，次晨许野也检查，之后继续查同类椅子、钥匙和库房，而不是跳过异常。白天仍有搬货、修门和抄账要做。

夏禾把六月六日的休息日告诉程见；傍晚才确定第二班车、回程和要带给许野的空白明信片。许野陪父亲复查，有自己的安排。出游不被写成程见单方面替她办好的一项差事。

王尔德《艺术家》的旧像/新像困境变成一次短暂的炉前试排。许野写的“释然微笑”演不下去，现实里的饭打断它，但饭没有解释死亡或治好悲伤。他们保留划掉的一页，约明天下午三点再试；完整改编仍留给后续章节。

半幅海景被补完，粗糙杯口后来也变平滑。杯子旧补块在共同路径交代，两个序章分支的读者都能理解。两条章末选择分别先问物证、先说自己的心意；都能看到杯子变化。夏禾说愿意等，不自动等于她被改写，程见也不能拿她过去的话压住她现在的决定。

本章 136 个图节点、41 段双语无配音叙述、68 句日语对白，一处行动分支与一个共同章末。中文旁白约 3535 字，另有对白。原作对白及试演均为原创；[王尔德公版原文](https://www.gutenberg.org/files/774/774-h/774-h.htm)只提供艺术材料与记忆的困境，没有照搬商业 Galgame 的台词。

## 美术与声音

沿用原四位角色和十张表情立绘，本章新增对白仅程见、夏禾、许野。新增六张 1920×1080 背景/特写：杂货铺早晨、河岸、杯口修补前后、完成的海景、带完整杯口的杂货铺暮色。白天与关店时的光线分开；原生图、生成中间稿、提示词、参考哈希与发布图清单在 `source-assets/paint-chapter-one/`，可用以下命令逐字节复现编码：

```sh
node scripts/package-paint-chapter-art.mjs --verify
```

声音继续用既有 Qwen3-TTS 原创合成参考，由本机 GPT-SoVITS v2ProPlus 合成 68 句正式日语，约 359.7 秒。没有换演员、下载真人声优素材或训练角色专用权重。八份参考与序章 SHA 相同；追加章节沿用原绑定，不创建新音色档案。预录章节直接播放，用户无需逐句点击生成。

WAV、参考、替补 take 与清单在 `assets/voice-packs/paint-chapter-one/`；运行 OGG 在 `apps/web/public/assets/audio/paint-chapter-one/`。音轨、日文、节点、角色及参考 SHA 一起校验。小模型 ASR 覆盖 68 句与八份参考，三句短句仍标为需复听；ASR 不判定情感、自然度或真人表演质量。详见[声音制作说明](../assets/voice-packs/paint-chapter-one/README.md)。

复用 TERNOX 的 CC0 实作配乐，异常调查和章尾停乐。未新增无来源的音乐；原 `paint-prologue/*-credits.json` 及 OtoLogic 音效署名继续保留。本章不强行叠加音效来制造惊吓。

## 安装与保护

依赖、数据库和账号初始化完成后：

```sh
pnpm demo:paint:seed
# 仅旧版 v1 单序章环境需要先运行 demo:paint:upgrade；已有两章时不运行旧升级命令。
pnpm demo:paint:chapter-one
pnpm test:paint
node scripts/export-paint-chapter-one.mjs
```

安装服务先核对原 demo 作者、固定 ID、公开发布状态、序章源内容/角色/封面/语言配置与现有声音绑定，再预检图像、配乐、全部对白文本和媒体哈希。事务内重新核对内容和章节版本，只追加 order=1，更新整部作品简介。序章节点、版本、时间戳、角色与参考绑定不变。结果已一致时返回 `current`，作者已有改写、额外章节或预检期间变化时拒绝；没有 force 选项。

后续修改已发布章节需要独立的显式升级和旧发布指纹，不能绕过安装保护直接覆盖作者数据。私人续写入口当前仍从序章的“我的下一句”开始，不自动把官方后续覆盖进现有副本。

播放器按存储顺序连续阅读，章节下拉可以直接进入某章；`?chapter=1` 为第二个实际章节，非法索引回到开头。切章清空本次阅读历史、停掉旧音乐与语音，不残留自动/跳过状态；作者 `preview/from` 仍需已登录且归属匹配。标题只转换开头的阿拉伯章号，保留“序章”、自定义标题及副标题日期。

长旁白在阅读层按段落、句号和自然停顿拆成约 64 字以内的短框，先读完当前框再进入下一框，源剧本、分支和音轨哈希不变。已配音对白保持完整字幕，本作中文对白最长 32 字，不需要切断一句表演。切页不重播音乐和素材音效；历史记录保存当前语言的每个已读短框，不重复整张长卡。切换字幕语言从当前卡第一个短框重新显示，返回原语言也不会恢复旧页码。
