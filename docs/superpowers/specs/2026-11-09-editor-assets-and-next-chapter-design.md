# 编辑器可用性与下一章

按用户持续授权自主设计与执行。先修复素材栏无法滚动的实际根因，保持原风格和保存机制；随后处理镜头卡审查中可复现的问题。前四章只作连续性复核，不用重写旧章掩盖问题。

素材栏设计：固定搜索/关闭/分类入口，只有素材正文在受限高度内纵向滚动。父级flex链提供min-height:0，窄屏占满可用宽度；不能用整页滚动或任意固定像素高度代替约束。录音样本登记等弹层也要能在小屏完成与返回。

编辑器设计：按旁白、对话、心理、回忆、系统、选项、跳转等现有镜头契约检查内容编辑、角色/背景/音频选择、排序、删除、复制、撤销和保存。只修改已复现的缺陷或有明确用户价值的缺口，不另外制造图谱副本。

剧情设计：复核序章至第三章及人物短篇的日期、已知事实和悬念，再推进第四章。接续陆青将读委托书与四月二十日三点排练；刘叔和沈芸在具体行动中出场，不只停留在档案。保持中文显示/固定日配、短框阅读、角色独立诉求；不取消试演等待，不把新NPC设为解释超自然的工具。

发布设计：新增内容必须具备完整正文、演出图、实际音轨与来源校验。新人物仅追加不改原角色；发布以冻结四章指纹、角色/媒体预检和事务CAS保护原章、私人副本及声音绑定。无法通过媒体或连续性检查的内容不写成“已经发布”。
