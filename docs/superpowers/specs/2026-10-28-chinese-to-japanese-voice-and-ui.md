# 中文输入、日语配音与全站视觉统一

用户补充：输入中文后选择日语配音，系统应自动翻译，而不是要求作者写日文。用户授权自行完成设计与实现，不等待逐项确认。

## 工作流

中文是创作源文本。配音语言是独立选择：中文直接生成；日语优先使用同一原文对应的官方/作者译文，否则自动翻译。用户可以查看实际朗读内容并调整译文，再生成试听。只有试听应用时，才把日文文本及其配音轨写回节点，中文字幕始终保留中文。

译文以原文哈希判定是否过期。改原文、角色或译文后，旧试听不能误应用。声音库也使用同一自动翻译 API，记录中文源文本和实际朗读文本。默认可使用 CPU 本机翻译，不要求小白配置额外 API；有已启用的在线模型时优先使用它。

## 已发现的语言问题

CosyVoice 的日文指令与参考模式均出现错读，独立 ASR 复查发现与目标台词明显不符。中文继续使用 CosyVoice；日文改用 GPT-SoVITS 的日文前端与日文参考。后台按目标语言自动切换，先等待旧进程退出再加载下一模型，避免 8GB 显卡同时驻留两套模型。失败的日文候选保留历史但标为失败。

## 角色绑定与批量生成

角色音色绑定保存在服务器，编辑器顶部集中配置。当前章节按角色自动分配参考片段和声线；批量生成只处理缺失、改稿或已换音色的对白，也提供显式重录。中文源文不变，自动翻译只生成独立日语译文和音轨。试听结果自动对应节点，可排除不满意的候选，再统一应用；一次撤销可撤回整批应用。生成过程中变更中文、译文、角色、音轨或绑定时保留新内容，不覆盖。

本轮配音语言记在当前浏览器的项目偏好中，单句重录沿用该偏好。声音绑定和已应用的音轨随项目保存在服务器；导出图谱保留语言音轨及音色来源 ID。

## 页面统一（实施）

沿用首页的浅灰底、白色卡片、紫色强调色和幻想插画。保留创作工具需要的内容密度，沉浸播放页面维持深色舞台。

- 统一素材库、创作 Agent、发现作品、设置的品牌头部与移动导航。
- 登录/注册共享品牌插画与表单布局，提供稳定返回入口。
- 发现页始终保留导航，增加分类、搜索、加载/失败/空结果状态。
- 设置改为明确的页标题、配置说明、保存动作和一致的卡片宽度。
- 声音库分梦弦音色/我的音色、样音语言和声线条件，区分样音语言与目标配音语言。
- 使用中文系统无衬线字体，统一焦点反馈、圆角、边框与主要动作。

## 验证

验证“只给中文、没有日文”的生成和应用；模型离线失败时不生成错误语种音频；源文本编辑后旧候选失效。运行服务器、网页和剧情域测试及 lint/build。实际浏览所有页面及宽/窄屏，检查导航、页面溢出、表单、配音试听、播放语言切换。
