# Homepage and automatic character dubbing

The user approves continuous gradients, whitespace and softly integrated imagery. Extend that direction on Home: a new original panoramic writing-room scene behind the hero, clear primary actions, a discoverable project shelf with search/status filters and accessible project actions, and three balanced illustrated workflow cards. Preserve existing create/import/export/rename/delete behavior.

Voice binding defines the speaker identity; each new passage still requires synthesis. The product should hide routine passage-by-passage operations. Add project-level **automatic dubbing while editing**, enabled when assigning a voice, with explicit pause/resume and manual direction available. Chinese dialogue remains authoritative; Japanese speech translates automatically and never replaces Chinese subtitles.

Automatic dubbing observes the current chapter after a writing pause, processes one pending passage at a time, automatically accepts/links completed audio, reuses matching queued/completed jobs after reopening, and leaves valid or manually provided audio intact. Priority goes to the currently edited scene, then remaining chapter dialogue. Before accepting/linking, recheck chapter, role, source text, reference/binding and existing audio/translation so newer edits or manual changes cannot be overwritten. Pause on service failure; expose a retry action instead of a retry storm. Leaving the editor stops subsequent submissions; a submitted server task may finish and is reusable next time. This iteration does not claim public runtime streaming or offline synthesis in exports.

Existing projects begin in manual mode until automatic mode is enabled or a voice is explicitly assigned. Newly assigning a voice enables automatic mode unless the author explicitly paused it. Keep manual batch generation and audition as a clearly labelled refinement mode; never run manual and automatic controllers concurrently. Automatic generated tracks are saved through the existing autosave coordinator.

References: Nuwa's public real-time protocol sends text and receives media streams; it does not disclose its internal synthesis segmentation. Qwen3-TTS documents streaming generation and reusable voice-clone prompts, but adopting a new provider is not needed to remove manual clicks from this project's existing local providers.
