# 双语配音与声音工作区设计

用户授权按合理产品判断直接设计和实现；沿用当前 main 本地工作区，不等待额外确认，不推送。

## 选择

采用单作品多语言文本/配音轨。复制两个项目会让分支和存档漂移；播放时在线翻译不能保证文笔与一致性。中文保持原始字段兼容，日文及后续语言放进节点本地化字段，字幕语言与配音语言独立。切换语言不改变剧情位置、变量、存档进度。

## 本轮交付边界

1. 声音库支持编辑档案、默认情绪和语速、停用/恢复、删除未引用档案和解除角色绑定。已引用档案返回具体阻止原因；不删除历史配音文件。
2. 节点保存中文与日文文本、选项及按语言的配音 URL。编辑器可以维护译文，播放器分别选择字幕和配音语言。缺译文回退中文并标记；缺音频不误播另一种语言。
3. 官方示例补全日文对白与选项。增加不同风格的合法合成参考音色与中日试听，质量仍标为候选。对照官方原生日语引擎与本机 CosyVoice，按实际资源和条款取舍，不下载动画角色录音进行克隆。
4. 音乐保留真人作曲 CC0 配乐，补充新场景曲目、适用场景和可追溯来源，不把程序化音调当成正式新配乐。
5. 素材界面使用统一声音工作区视觉：一张原创录音室插画、清晰内容层级、卡片与侧边编辑面板、持续播放器、异步失败反馈。装饰图不含文字，不影响阅读或可访问性。

## 数据原则

多语言结构为 `localizations: { ja: { text?, choices?, speaker? } }`，音频为 `voiceTracks: { zh?: {url, volume?}, ja?: {url, volume?} }`。原始 `text`、`choices`、`audio.voice` 保持中文兼容。语言是字幕/音频轨属性，不由音色名称猜测。用户修改原文不自动覆盖译文，编辑界面提示同步检查。

## 验收

检查字幕切换时剧情位置不变、选项顺序不变、缺配音时静音、文本变更导致对应配音过期。验证档案删除被引用阻止、无引用可删除、编辑后列表同步、解除绑定后生成按钮禁用。对新增素材检查来源与哈希、在浏览器验证音频有效，在宽窄布局检查编辑和播放器无遮挡。
