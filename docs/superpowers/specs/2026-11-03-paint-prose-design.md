# 序章叙事重修

用户认为第一版开场突兀、故事性弱、对白过密，明确要求继续参考其偏爱的文学系视觉小说，以及名著、意象和描写。保留已批准的画中世界主案与人物，直接执行叙事修订，不再要求重复审批常规文案取舍。

## 取舍与目标

评估三条路：仅给旧对白加形容词仍解决不了人物入场；彻底另起主案会丢掉已审核的世界规则；选择重写序章的叙事组织，保留核心事件和已完成的固定角色声音，补出起因、当下欲望、内心视角、戏剧行动和结束后的余韵。

开场为程见家中的下午与一张入场券。夏禾写“七点，第一排。今天不许帮忙。”他本来是被邀请的观众，却提前去工房，把自己的座位让给临时来的观众，最终没看完整场戏。散场留座不再只是可爱的插曲，而是兑现被他自己延后的邀请。椅子作为第九个座位与标题对应。

四组场景的图谱结构不变：入场券/工房、八位观众、散场、深色补笔。开场增加居室背景，工房内部增加小物特写；对话串分为两三句一组，用动作、感官、内心反应连接，不用长墙文字一次塞满对白框。

## 互文与意象

- 宫泽贤治《银河铁道之夜》关于真正幸福的疑问作为短题记，自译并注明来源。程见的“为他人做事”与接受朋友的照顾在行动中回应，序章不替全篇下哲学结论。
- 王尔德《艺术家》出现在许野读过、试图搬上舞台却尚未解决的旧书里。永久悲哀与瞬间快乐构成他写家常小戏的背景问题，之后章节再真正改编演出。本章不偷跑后续高潮。
- 入场券：邀请→未使用的完整票根→散场后的座位→明天仍应被兑现的具体生活。
- 窗/未画完的海：可见的远方与夏禾自己的愿望，舞台旧海景布景有尚未填满的白，不是装饰性花瓣。
- 深色补木：修理改变旧物，改变使其继续承重；被回填抹除的是一段真实劳动与共同生活。

原文参考与解释必须区分。中国字句为原创，自译短引文注明原作者；不复制商业Galgame台词，不模仿特定在世作者的行文声纹。保留生活质感与局部幽默，避免所有人轮流讲观点。
