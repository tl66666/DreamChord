# DreamChord 声音库与 GPT-SoVITS 配音设计

日期：2026-10-23

## 目标

把现有“上传一段角色声音样本、由 Agent 给出制作计划”的能力，升级为可跨项目复用的声音库。作者能够管理自己有权使用的音色，把音色绑定到项目角色，在编辑阶段批量生成、试听和确认对白候选；正式 Galgame 播放器只播放已确认的 `VOICE` 素材，不在游玩时等待模型推理。

## 参考与取舍

- Nuwa 的公开资料展示了“上传短录音形成可复用音色、再调节语速/音高/情绪”的产品路径。其工作台需要登录，本设计不臆测或复制其私有界面，仅采用声音资产化和显式复用的通用思路。
- Paper2Gal 把自动配音设计为进入内容前的可选能力，并提示网络生成会有等待。本项目保留“自动配音”开关，但将生成移动到编辑器的制作队列，避免正式播放卡顿。
- WebGAL 将语音播放与编辑器预览、运行时状态分离。DreamChord 继续使用现有 `audio.voice` 播放通道，不引入另一套脚本语言或播放器内 TTS。
- GPT-SoVITS 提供本地 HTTP API，适合零样本/少样本中文角色配音。第一版只对接作者自行运行并已配置好的实例，不代替用户下载模型、训练权重或管理显卡环境。

## 核心模型

### 音色档案 VoiceProfile

全局、用户私有、可跨项目使用：

- 名称、说明、语言、年龄感、性别感和风格标签；
- 提供方与模型标识；
- 默认语速、情绪和随机种子策略；
- 授权状态、授权备注和创建时间；
- 一段已确认的预览音频；
- 启用/停用状态。

“性别感、年龄感”只用于作者筛选和表演方向，不把它们当作对真实人物身份的判断。

### 参考片段 VoiceReference

一个音色可以包含多条参考片段：

- 原始 `VOICE_SAMPLE` 素材；
- 与录音完全一致的文字稿和语言；
- 情绪/场景标签；
- 时长、格式与基础质量检查结果；
- 授权确认和可撤销状态。

GPT-SoVITS 零样本默认优先选择 3–15 秒、单人、无音乐、无混响、文字稿准确的片段。较长素材可以保留在档案中，但不自动作为推理参考。

### 角色绑定 CharacterVoiceBinding

项目角色只保存到全局音色档案的绑定，不复制参考音频。删除项目不会删除声音库；停用或删除音色时，绑定失效但既有已确认对白仍可播放。

### 生成任务 VoiceGenerationJob

任务状态为 `QUEUED / RUNNING / READY / FAILED / ACCEPTED / REJECTED`，记录项目、角色、镜头、对白、参考片段、提供方参数、错误信息和生成来源。生成结果先作为候选试听；作者接受后才进入正式 `VOICE` 素材库并可绑定到镜头。

## 用户流程

1. 在“素材库 → 声音库”创建音色档案。
2. 上传有权使用的参考录音，填写准确文字稿、语言和表演标签，并确认授权。
3. 在项目角色设置中选择音色；同一音色可绑定多个自有角色，但界面提示避免滥用真人声线。
4. 在章节或角色范围创建生成任务，可选择“仅缺失对白”并限制批量数量。
5. 在候选列表逐条试听、重试、接受或拒绝。接受不会自动覆盖已有配音。
6. 绑定后的 `VOICE` 素材进入现有音频导演和播放器；服务不可用时仍可手动上传配音。

## GPT-SoVITS 适配

服务端实现提供方接口，浏览器不直接访问 GPT-SoVITS，也不接收任意服务地址：

```ts
interface VoiceProvider {
  health(): Promise<{ ok: boolean; message: string }>
  synthesize(input: {
    text: string
    textLanguage: string
    referencePath: string
    promptText: string
    promptLanguage: string
    speed: number
    seed?: number
  }): Promise<{ bytes: Buffer; mimeType: string; seed?: number }>
}
```

环境变量：

- `VOICE_PROVIDER=gpt-sovits`
- `GPT_SOVITS_BASE_URL=http://127.0.0.1:9880`
- `GPT_SOVITS_TIMEOUT_MS=120000`

第一版要求 GPT-SoVITS 与 DreamChord 服务端位于同一机器，或共享参考音频目录。适配器只访问配置文件中的固定地址，并拒绝用户提交 URL，避免服务端请求伪造。由于 GPT-SoVITS 管线与权重状态是全局的，DreamChord 第一版使用单并发队列，不在任务之间自动切换权重。

## 界面

声音库采用“目录 + 详情”结构：顶部搜索和语言/风格/状态筛选；卡片展示音色名称、标签、试听、参考片段数、服务状态和已绑定角色数；详情区展示授权、参考片段质量、默认参数和生成历史。

编辑器中的角色音色面板显示：当前绑定、试听、进入声音库、生成缺失对白。生成按钮旁明确显示提供方在线状态；离线时保留脚本导出和手动上传入口。

## 安全与版权

- 每条参考录音都必须由作者主动确认拥有本人同意或合法授权。
- 默认仅用户本人可见，不提供公共声音市场和真人名人预设。
- 音色删除、停用和授权撤销必须可追踪；撤销后禁止新生成。
- 正式音频记录提供方、参考片段、参数、生成时间和操作者，便于追溯。
- 日志不输出音频正文、参考音频绝对路径或访问令牌。

## 降级与错误

- 未配置提供方：声音库、绑定、脚本和人工上传继续可用，生成按钮显示配置指引。
- 服务离线或超时：任务标记失败并保留可重试信息，不创建半成品素材。
- 参考片段不合格：阻止提交并说明缺少文字稿、格式不支持、时长异常或授权未确认。
- 生成失败：不改变镜头当前配音；重试创建新尝试并保留历史。
- 删除候选：删除生成文件并记录拒绝状态；已接受的正式素材按现有安全删除规则处理。

## 第一阶段范围

实现声音库的数据模型、授权参考片段、角色绑定、提供方健康检查、单并发任务和 GPT-SoVITS 适配器；提供最小可用的库与候选审核界面。

暂不实现模型训练、自动下载/启动 GPT-SoVITS、在线付费 TTS、实时口型、声纹认证、公共音色市场以及游玩时即时生成。
