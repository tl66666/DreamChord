# 编辑器、Agent 与音乐控制

用户已授权自主设计并实施。本轮保留章节—场景—镜头工作台与草案审批，不重做整体视觉。

1. 模型：设置页和 Agent 直接填写服务平台模型 ID；保留旧配置；保存校验、存储失败提示；不再猜测新版型号。修改 `lib/aiConfig`、`SettingsPage`、`AgentComposer`，添加可复用模型输入。
2. Agent：修正显式修改目标被当前选中场景覆盖；空目标不能提交；启动阶段防重复、错误保留输入；配置往返保留当前会话输入。
3. 音乐：镜头内百分比音量、延续音量覆盖和淡入淡出；修复转换器遗漏参数与同曲重播；选中镜头预览继承可达路线的音乐，不重放旧音效和配音。
4. 示例：提高官方曲目电平，保留对白压低；只更新官方固定项目中仍与旧默认一致的音乐配置，不改用户作品。
5. 验证：先补行为回归并确认失败，再实现；检查桌面、平板和手机；全量测试、lint、build，独立审查后更新交接并提交。

参考：Ren’Py 官方 Audio 文档中曲目音量、独立混音通道、淡变控制；WebGAL 的背景音乐音量/淡入参数。采用适合工作台的紧凑分组，不添加干扰写作的装饰图。
