# 谢幕词上的那一句：试玩到第一次创作

用户已确认产品方向：官方示例首先让用户体验梦弦能做什么，再自然接手创作。采用大学毕业晚会短剧，主线约 5–8 分钟、三个成年角色、一次选择、两个完整结尾。用户批准自主完善和实现；不再重复索要选题审批。

剧情：22 岁的林澈和许栀主持毕业晚会最后的谢幕；好友唐棠负责舞台执行。许栀明早去外省工作，林澈留城读研。两人都知道去向，问题在于始终没有认真谈过以后如何相处。许栀划掉两人去年写下的“明年，也一起站在这里吧”。排练中的玩笑、共享小物和几次说到一半的话建立关系；最后由玩家选择保留一句远期约定，或改成祝福并在清晨亲自送行。她的工作与选择保留，结尾有具体行动与回应。

产品结构：开场有配音和画面；前一分钟交代人物、目标与离别；一次选择进入不同场景和结局。结束页主按钮“写下你的第三种结局”，次按钮重读或体验另一种选择。登录后复制出用户拥有的新作品，人物、图片、配乐、有效双语音轨与可继续合成的官方授权参考一起带入。复制不改变原作品，不引入原作者私有上传或私人声纹；新 ID 全部重映射。开始创作定位到预留的第三种结局，提供短引导；选择镜头卡、修改台词与表情、预览，不再要求重新配置素材。

声音：现有 Qwen 预置合成音色仅作可追溯合成参考来源；同文本比较 GPT-SoVITS 与 Qwen，技术检查、ASR 为辅助。新故事优先 GPT-SoVITS 中日生成，记录实际引擎、权重版本、参考、台词、哈希和时长；不得宣称真人克隆或完成专属训练。中文原稿保留，日语配音与中文字幕独立。GPT-SoVITS 设为本机首选，CosyVoice 保留可选配置。

美术：统一大学六月毕业夜的暖金、暮蓝、少量淡紫；背景为后台、礼堂舞台、夜间校园、清晨车站；三位角色各三表情透明全身源图，正式舞台半身。生成结果保存进项目，记录提示和来源。配乐从已授权真人作曲素材挑选，声效用已有可核实 CC0/CC BY 素材或自制真实录音；对白关键处让音乐退下，不铺满所有段落。
